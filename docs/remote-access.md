# Доступ с телефона

Модели всегда работают на Mac. Телефон служит микрофоном и экраном. Основной сервер (`:4317`) никогда не слушает внешние интерфейсы. Для телефона поднимается отдельный мост с авторизацией, который проксирует запросы на loopback.

Есть два режима. Оба используют `lib/mobile.mjs` (`createMobileBridge`).

| | LAN (`npm run mobile`) | Туннель (`npm run remote`) |
| --- | --- | --- |
| Сеть | Одна частная сеть или хотспот iPhone | Любая, через Cloudflare Quick Tunnel |
| TLS | Свой локальный CA, профиль ставится на iPhone | Сертификат Cloudflare, на телефоне ничего ставить не нужно |
| Порты | HTTPS `:4319`, раздача CA по HTTP `:4320` | Loopback-мост `:4321` |
| Данные | Не покидают локальную сеть | Аудио и текст проходят через Cloudflare |
| Статус | Проверен с Mac. На физическом iPhone с микрофоном — нет | Проверен вход браузером, HTTPS, AudioWorklet. Запись с iPhone не проверена |

Общие свойства обоих режимов: строгая проверка Host/Origin, случайный 12-символьный код входа, обмен кода на Secure, HttpOnly, SameSite cookie (30 дней), лимит 8 неудачных входов в минуту. Прокси-заголовки и cookie клиента не доходят до основного сервера. Записывать одновременно может только один клиент: ASR-воркер общий.

## LAN: `npm run mobile`

Держи `npm start` запущенным. Во втором терминале:

```sh
npm run mobile                  # сам выберет частный IPv4, предпочитая хотспот iPhone
npm run mobile -- 172.20.10.3   # или конкретный адрес
```

Скрипт выведет ссылку на сертификат, персональную ссылку для входа и код.

1. Открой ссылку на сертификат в Safari и установи профиль **Claro Local Development**.
2. Включи доверие: **Настройки → Основные → Об этом устройстве → Доверие сертификатам**. Приватный ключ CA остаётся на Mac.
3. Открой ссылку для входа (или `/mobile` и введи код).
4. **Поделиться → На экран «Домой»**, затем запускай Claro с иконки. Держи приложение на переднем плане во время записи.

Ключи и учётные данные лежат в `.runtime/mobile/` (права 600). Никогда не коммить и не передавай этот каталог. Учётные данные переживают перезапуск моста. Чтобы отозвать все подключения, останови мост, удали `credentials.json` **и** `connection.json` и запусти мост заново. При смене IP перезапусти мост и заново добавь иконку на экран «Домой». Когда профиль CA больше не нужен, удали его с iPhone.

## Туннель: `npm run remote`

**Включай осознанно:** аудио и текст пойдут через Cloudflare. Это временный туннель, не VPN и не сквозное шифрование.

```sh
npm run remote
```

Скрипт создаёт туннель к loopback-мосту `:4321` с чистым конфигом cloudflared, без аккаунтного. Адрес и код записываются в `.runtime/remote/connection.json` (600) и удаляются при Ctrl+C. Пока туннель работает, Mac не уходит в сон в простое, но закрытая крышка его всё равно усыпит. Не публикуй ссылку и код и не коммить их.

## Будущее: приватная сеть

Для постоянного доступа рекомендуется Tailscale Serve: приватный HTTPS только для своих устройств, без Cloudflare. Сейчас не установлен. Для интеграции нужен адаптер внешнего origin и входа по коду, как в туннельном режиме. Отключать проверки origin или открывать порт инференса нельзя. См. [Tailscale Serve](https://tailscale.com/docs/features/tailscale-serve).
