# Дорожная карта Claro

Claro — языковой компаньон: помогает понимать речь в моменте и превращает услышанное в занятия. Три сценария используют одни и те же записи реплик:

1. **Смотреть** — новости, подкасты, видео на другом языке с живыми субтитрами и переводом под словами.
2. **Разговаривать** — живой диалог с носителями: субтитры собеседника, перевод при необходимости, сохранение диалога.
3. **Учиться** — разбор своих ошибок, сводные темы из разных диалогов, карточки из незнакомых слов.

Во время просмотра и разговора важна скорость. После них можно не спешить: заново проверить текст, разметить говорящих, подготовить урок.

## Принципы

- **Браузер вместо отдельного приложения.** Claro — локальный сервер и веб-интерфейс. Устанавливается как PWA: своё окно, иконка в Dock, без адресной строки. Один и тот же интерфейс на компьютере и телефоне.
- **Запуск в пару кликов.** Одна команда установки, дальше иконка, которая поднимает сервер и открывает окно.
- **Локально по умолчанию.** Аудио и текст не покидают компьютер. Внешние сервисы — только по явному выбору.
- **Работает и без тяжёлых моделей.** Режимы установки: «Лёгкий» на встроенных моделях системы, «Стандарт» (Qwen3-ASR + TranslateGemma, ~4 ГБ), «Полный» (плюс модель для уроков).
- **Минималистичный, понятный интерфейс.** Сначала карта экранов и сценарии, потом визуальный стиль.

## Возможности браузера

| Задача | Как в браузере | Ограничения |
| --- | --- | --- |
| Звук с микрофона | `getUserMedia` (уже работает) | — |
| Звук видео и подкастов | `getDisplayMedia` со звуком вкладки или системы | Chrome/Edge. Safari звук вкладки не отдаёт. Системный звук целиком зависит от версии Chrome и macOS — проверить |
| Субтитры поверх видео | Document Picture-in-Picture: маленькое окно поверх всех приложений с обычным HTML | Только Chrome/Edge. Окно запускается по нажатию пользователя |
| Окно «как приложение» | PWA: установка из Chrome, отдельное окно и иконка | Сервер должен быть запущен |
| Хранение диалогов | Сервер, встроенный `node:sqlite` | Node 22.5+ |
| Телефон | Тот же интерфейс через приватную сеть | Нужен мост (LAN или Tailscale) |

## Модули

| Модуль | Ответственность |
| --- | --- |
| Источники звука | Микрофон, вкладка или системный звук, позже файл. У каждого потока свой источник и время |
| Детектор речи | Отделяет речь от пауз и шума. Кандидат — [Silero VAD](https://github.com/snakers4/silero-vad) |
| Распознавание | Черновик и готовая реплика с общим ID. Qwen — живой текст, другой движок — проверка после записи. Для режима «Лёгкий» — встроенные модели системы |
| Перевод | Фразы и значения слов в отдельных очередях. Плюс разметка устойчивых выражений, чтобы нажатие выделяло фразу целиком |
| Сессии и хранение | Диалоги, реплики, время, участники, нажатые слова. Аудио — только при явно включённой записи |
| Голоса | Образец своего голоса → «Я / собеседник» вживую. Полная разметка всех говорящих — после разговора ([pyannote Community-1](https://huggingface.co/pyannote/speaker-diarization-community-1)) |
| Разбор языка | Ошибки в своих репликах с метками тем. Сводка тем по всем диалогам. Отличает «я так сказал» от «программа так услышала» |
| Карточки | Интервальное повторение (FSRS). Источники — нажатые слова, ошибки, ручное добавление. Пример берётся из реального диалога |

Общий формат реплики: ID сессии и реплики, время начала и конца, язык, исходный текст, ревизия, говорящий. Перевод, исправления, карточки и уроки ссылаются на конкретную ревизию реплики. Тяжёлые задания после разговора уступают ресурсы живому распознаванию.

## Реалистичность

- **Свой голос** распознаётся надёжно в тихой обстановке после записи образца. Самый надёжный вариант — свой петличный микрофон.
- **2–3 собеседника** вживую различаются прилично. Шумная компания и перебивания — слабое место. Там помогает разметка после разговора.
- **Разбор ошибок** зависит от качества распознавания: ASR может «исправить» ошибку или добавить свою. Сомнительные места помечаются, а не выдаются за ошибку ученика.
- **Задержка субтитров** к видео — 1–3 с. Для новостей и подкастов это нормально. Если у видео есть свои субтитры, их можно брать напрямую.

## Этапы

| Этап | Что должно работать к концу этапа |
| --- | --- |
| **1. Фундамент** | Код разбит на модули и читаем. Диалоги сохраняются в SQLite, их можно открыть после перезапуска |
| **2. Продуктовый дизайн** | Карта экранов: Разговор, Просмотр, Библиотека, Уроки, Карточки, Настройки, первый запуск. Выбран визуальный стиль, собрана дизайн-система |
| **3. Запуск в пару кликов** | Одна команда установки с выбором режима. Иконка запускает сервер и окно PWA. Мастер первого запуска проверяет модели и микрофон |
| **4. Режим просмотра** | Звук вкладки или системы, окно субтитров поверх видео, нажатие на слово или фразу, сбор «непонятного» |
| **5. Обучение** | Разбор диалогов, сводные темы, карточки с повторением |
| **6. Голоса** | Образец своего голоса, «Я / собеседник» вживую, разметка после разговора |
| **7. Телефон и релиз** | Приватный доступ с телефона, синхронизация через Mac, документация установки для всех |

Качество и скорость распознавания проверяются замерами на открытых записях ([испанский FLEURS](benchmarks/fleurs-es.md)), без личных записей.
