# Claro на открытых испанских записях FLEURS

8 ноября 2026, Apple M4, 16 ГБ. Входные данные — [Google FLEURS](https://huggingface.co/datasets/google/fleurs), [испанская часть `es_419`](https://huggingface.co/datasets/google/fleurs/tree/4683b04/data/es_419), редакция `4683b04`, раздел `dev`, лицензия CC BY 4.0. Это чтение предложений на латиноамериканском испанском. Выборка не оценивает разговор двух людей, шум помещения или другие языковые варианты.

## Распознавание готовых аудиофрагментов

48 записей с разными идентификаторами текста, по 24 записи с каждой из двух меток пола в FLEURS. Всего 968 эталонных слов и 463,32 с аудио. Один и тот же фрагмент подаётся обеим моделям после прогрева, порядок вызовов меняется. Сценарий использует рабочий локальный сервер Claro. Скорость — `processing_ms` от сервера, который включает вызов движка и получение результата. p50 и p95 рассчитаны методом ближайшего ранга.

| Конфигурация | p50 | p95 | Ошибки в словах | После склейки переносов внутри слов |
| --- | ---: | ---: | ---: | ---: |
| Qwen3-ASR 0.6B MLX 4-bit | 0,857 с | 1,580 с | 60/968 (6,2%) | 60/968 (6,2%) |
| Whisper large-v3-turbo, whisper.cpp 1.9.2 | 3,229 с | 4,263 с | 72/968 (7,4%) | 38/968 (3,9%) |

WER — сумма замен, пропусков и вставок на число эталонных слов. Регистр и пунктуация игнорируются. Различия вроде `80` и `ochenta` могут считаться ошибками. В 16 ответах Whisper встречались переносы внутри слов. Дополнительный пересчёт удаляет только перевод строки без пробелов между двумя буквами. Исходные ответы сохранены, поведение приложения при этом не меняется. Разница между двумя столбцами показывает вклад форматирования в результат.

- Qwen заменил `gravaron con aranceles` на `grabaron con Aries` (фраза 1566).
- Whisper заменил `Estas doctrinas sostienen` на `Esta doctrina sostiene` (1549) и разорвал `turístico` на две части (1638).
- Обе модели распознали `del agente de viajes` как `de la gente de viaje` (1657).

## Подача аудио в реальном времени

Четыре записи из той же выборки длиной 6,66–7,32 с. Использованы очередь и границы аудио из Claro, шаг обновления 1,5 с, пауза 1,2 с, предел сегмента 8 с. Время отсчитывается от начала подачи аудио. Параллельный перевод выключен.

| Конфигурация | Первый непустой текст, p50 | Последний готовый текст, p50 | Ошибки в словах | Потерянные задания |
| --- | ---: | ---: | ---: | ---: |
| Qwen3-ASR 0.6B | 3,044 с | 7,215 с | 0/54 | 0 |
| Whisper Turbo | 5,786 с | 12,831 с | 2/54 | 0 |

Обе ошибки Whisper в этом прогоне вызваны одним переносом внутри `temática`. После склейки обе модели распознали все 54 слова. Четыре записи дают ориентир по задержке на этом Mac, а для оценки качества полезнее выборка из 48 записей.

## Перевод с испанского на русский

20 предложений с общими идентификаторами в испанском и русском разделах `dev`. На вход подавался эталонный испанский текст. Обе установленные модели проверены через их штатные профили Claro в Ollama после отдельного прогрева, без одновременного распознавания речи. Значения p50 и p95 измеряют время до готового перевода.

| Модель | p50 | p95 | chrF2 из 100 |
| --- | ---: | ---: | ---: |
| TranslateGemma 4B | 3,589 с | 4,630 с | 48,0 |
| Qwen3 4B | 4,029 с | 5,888 с | 42,6 |

Модели вернули все 20 ответов. [chrF2](https://aclanthology.org/W15-3049/) измеряет совпадение символьных последовательностей с одним русским эталоном. Синонимы и другие допустимые формулировки могут снижать балл. Для проверки смысла полезно смотреть отдельные расхождения.

- TranslateGemma перевела «еврейские семьи» как «израильские семьи» (1582) и потеряла смысл водного течения в пользу «выбраться из этой ситуации» (1560).
- Qwen3 вернула предложение о произношении итальянского почти полностью по-английски (1559).
- Обе модели поняли `pueblo` как город там, где предложение говорит о народе (1631).

Для текущего Claro результаты поддерживают Qwen3-ASR 0.6B в качестве основного движка живых субтитров и TranslateGemma 4B для перевода фраз. Whisper стоит повторно оценить с корректной сборкой сегментов, особенно для режима проверки готового текста.

## Интервал обновления Qwen

9 ноября 2026. Двенадцать отдельных испанских фраз FLEURS по 4–7,5 с, 148 эталонных слов. Оба интервала прогнаны на каждом фрагменте, порядок менялся. Тест использовал Qwen3-ASR 0.6B, паузу 1,2 с и предел сегмента 8 с. Время отсчитывалось от начала подачи аудио. Перевод был выключен.

| Интервал | Первые слова, p50 / p95 | Готовый текст, p50 | Ошибки в словах | Запросы к распознаванию |
| --- | ---: | ---: | ---: | ---: |
| 1,5 с | 2,702 / 3,880 с | 6,700 с | 9/148 | 38 |
| 1,0 с | 2,177 / 3,227 с | 6,785 с | 9/148 | 59 |

При интервале 1,0 с первые слова появились на 0,525 с раньше по p50. Готовый текст и число ошибок практически совпали. Потерь заданий в обоих режимах не было. Запросов стало на 55% больше, суммарное время работы распознавания по этим запросам выросло с 8,66 до 14,32 с. Перед выбором интервала по умолчанию нужно проверить конкуренцию с переводом и качество на шумных записях.

## Как повторить

Для локального прогона нужны запущенный Claro, установленные модели, Node.js и `ffmpeg`. Источники для рабочего каталога `.runtime/eval-fleurs-es` — [испанский dev.tsv](https://huggingface.co/datasets/google/fleurs/resolve/4683b04/data/es_419/dev.tsv), [испанский dev.tar.gz](https://huggingface.co/datasets/google/fleurs/resolve/4683b04/data/es_419/audio/dev.tar.gz) и [русский dev.tsv](https://huggingface.co/datasets/google/fleurs/resolve/4683b04/data/ru_ru/dev.tsv), который сохраняется как `ru-dev.tsv`.

```sh
node scripts/benchmark-fleurs.mjs .runtime/eval-fleurs-es asr
node scripts/benchmark-fleurs.mjs .runtime/eval-fleurs-es live
node scripts/benchmark-fleurs.mjs .runtime/eval-fleurs-es cadence
node scripts/benchmark-fleurs.mjs .runtime/eval-fleurs-es translation
```

Сценарий выбирает одинаковые записи по фиксированному хешу имени файла. В рабочем каталоге остаются исходные данные и отчёты `asr.json`, `live.json`, `cadence.json` и `translation.json` с эталонами, результатами и временем по каждому примеру. Все вызовы моделей идут через локальные адреса.
