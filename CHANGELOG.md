# История изменений

Все версии выпущены 8–9 ноября 2026.

## Не выпущено

- Добавлены локальные карточки из окна слова с примером и переводом реплики, раздел после Библиотеки, изменение и удаление, интервальное повторение с четырьмя оценками и клавишами 1–4. Миграция SQLite v2 сохраняет разговоры; карточки переживают удаление источника. API `/api/cards*` защищён токеном, без хранилища возможность скрыта.

- Добавлен режим «Просмотр» со звуком вкладки или системы, общей лентой субтитров и сессиями `watch` в библиотеке. В Chrome и Edge доступно окно поверх видео с переводом и значениями слов, оформленное внешними стилями приложения. Нажатия на слова во время разговора или просмотра публикуют событие `lookup` в шину модулей. Недоступные возможности показывают причину, на телефоне раздел просмотра скрыт.

- Добавлены установка одной командой для macOS 14+ на Apple Silicon, общий `npm run setup` с `--lite`, повторное использование локальных моделей и дописывание недостающих настроек. Ярлык открывает окно и управляет сервером, предусмотрено удаление с подтверждением для данных и проекта. Модели перевода и значений слов прогреваются при запуске, интерфейс показывает причины неготовности и команду установки, добавлена установка приложения через браузер.

- Добавлена «Библиотека» сохранённых разговоров с группировкой по дням, поиском по названию и превью, чтением сохранённых переводов и значений слов, переименованием, удалением и экспортом TXT / JSON schema v2. Текущий разговор можно продолжить. Без серверного хранилища доступна история вкладки.

- Обновлён дизайн «Лента» для телефона и компьютера. Добавлены системная, светлая и тёмная темы, пять палитр с применением до первой отрисовки, сегмент вида перевода, капсула записи с уровнем и таймером, контекстное окно слова и сгруппированные настройки с живым образцом. Значения слов переносятся полностью, свои реплики расположены справа, повторные подписи участников скрыты.

- Добавлено локальное SQLite-хранилище разговоров с защищённым API, автосохранением готовых реплик, переводов, значений слов и участников, восстановлением активного разговора, завершением и удалением. Сохранение отключается в настройках или через `CLARO_STORAGE=off`, каталог задаётся `CLARO_DATA_DIR`. Требуется Node.js 22.13+.

- Клиент разбит на нативные ES-модули с общим состоянием. Поведение сохранено, тестовый стенд загружает настоящие модули, таблица статики сервера объявлена один раз.
- Документация реорганизована: README, architecture, setup и remote-access описывают текущее состояние, история версий собрана в этом файле.
- Код сервера, клиента, скриптов и стили переформатированы для читаемости. Поведение не изменилось.

## 0.11 — полный текст и удалённый доступ

- Значения слов отображаются полностью: ячейки естественной ширины и высоты, без многоточий и обрезки. Прежняя гарантия фиксированной геометрии (v0.9–0.10) отменена.
- В спокойном режиме подстрочник появляется одним пакетом (`gloss_status=ready`).
- Убраны повторяющиеся метки «Пример», время и служебные пояснения в облачках. Остался один индикатор «Демо» вне сообщений.
- Финальные фразы сохраняют идентичность при изменении ширины окна.
- `npm run remote`: временный туннель Cloudflare к loopback-мосту `:4321` с входом по коду. `createMobileBridge` поддерживает закреплённый внешний HTTPS-origin.

## 0.10 — спокойное чтение и режим peek

- Режим чтения «Спокойно» (по умолчанию): живой черновик отдельно, в ленту попадают только готовые реплики. Режим «Сразу» сохраняет прежнее поведение.
- Режимы перевода: всегда, по нажатию, peek (подготовить и скрыть), без перевода.
- `splitFinalCaption`: деление по предложениям с `source_record`. Предел аудиосегмента — 8 с.
- Отмена запросов через `AbortController` вплоть до Ollama. Значения слов ждут освобождения очередей ASR и перевода.
- Светлая тема: тихие границы, без теней у сообщений.

## 0.9 — мессенджер, полный подстрочник, участники

- Интерфейс в стиле мессенджера со светлой и тёмной темами, крупным текстом и настройками в диалоге (на телефоне — нижний лист).
- Полный подстрочный перевод: значение для каждой единицы текста, валидация по позициям, `features.full_interlinear`.
- Ручные участники: имена, цвета, профиль «Я». Экспорт JSON v2.
- `public/modules.js`: объявление возможностей и шина событий.

## 0.8 — потоковые подсказки

- Значения слов приходят по ходу генерации через `/api/gloss-stream`.

## 0.7 — блоки чтения

- Сегменты хранят ID, исходный текст ASR, сессию захвата и время. `readingBlocks` объединяет их для отображения, не меняя исходные записи.

## 0.5 — лента разговора

- Подписи хранятся по ID, строки обновляются на месте. Вьюпорт `100dvh`, прокручивается только лента. Следование за новыми сообщениями и кнопка «К новым».

## До 0.5

- Потоковый перевод (`/api/translate-stream`), Qwen3-ASR через MLX, сравнение с Whisper, LAN-мост к телефону с локальным CA, первые версии интерфейса. Подробности не задокументированы.
