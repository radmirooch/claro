# Установка и настройка

Все загрузки моделей и бинарников — явные команды установки. `npm start` ничего не скачивает.

## Установка одной командой

Поддерживаются macOS 14+ и Apple Silicon. Нужно около 6 ГБ места, 8+ ГБ RAM, рекомендуется 16 ГБ.

```sh
curl -fsSL https://raw.githubusercontent.com/radmirooch/claro/main/install.sh | bash
```

Установщик проверяет платформу, Node.js 22.13+, git и uv. При необходимости предлагает `brew install node` с подтверждением через `/dev/tty`, устанавливает uv официальным установщиком и запускает общую установку моделей. Если git отсутствует, выполни `xcode-select --install` и повтори команду. Без Homebrew Node.js нужно установить с https://nodejs.org.

Проект размещается в `~/Claro`. Для другого пути задай `CLARO_HOME`.

```sh
curl -fsSL https://raw.githubusercontent.com/radmirooch/claro/main/install.sh | CLARO_HOME="$HOME/Apps/Claro" bash
```

При повторном запуске для установленной папки выполняется `git pull --ff-only`. Из существующего репозитория можно запустить `./install.sh`, установка выполняется в этой папке. Ярлык `~/Applications/Claro.command` ведёт на `start.command` проекта.

## Ручная установка и флаги

После получения репозитория перейди в его папку, установи Node.js 22.13+ и uv. На Mac с Apple Silicon выполни общую установку.

```sh
npm run setup
npm run setup -- --lite  # распознавание и перевод, без скачивания модели значений слов
```

Обычная установка включает Qwen3-ASR, Ollama с TranslateGemma 4B и Qwen3 4B для значений слов. `--lite` пропускает Qwen3 4B, уже скачанные модели сохраняются. Чтобы позднее добавить значения слов, выполни `npm run setup` без флага.

Скрипт проверяет пакет Qwen и локальный снимок, манифесты и размеры файлов Ollama. Повторная установка при наличии всех файлов проходит без загрузок и запуска Ollama. Прерванную загрузку можно продолжить повторным запуском. `.env` создаётся при отсутствии, в существующий файл дописываются только отсутствующие `OLLAMA_MODEL`, `OLLAMA_URL` и `OLLAMA_BIN`. Существующие значения, включая пустые, сохраняются. Если используются собственные адреса или модели, проверь соответствие настроек установленным моделям.

На остальных платформах установи Node.js, Whisper.cpp с мультиязычной моделью и Ollama средствами своей системы, затем настрой их по разделам ниже. Qwen MLX требует Apple Silicon. `npm install` для приложения не нужен.

## Требования

- **Node.js 22.13+**. У Node-части нет npm-зависимостей, `npm install` не нужен.
- **macOS на Apple Silicon** для Qwen3-ASR (MLX/Metal). Whisper.cpp и Ollama работают и на других платформах, но там проект не проверялся.
- **uv** — для Python-окружения Qwen.
- **OpenSSL** — только для LAN-моста к телефону (`npm run mobile`).
- **cloudflared** — только для временного туннеля (`npm run remote`).

## 1. Распознавание речи (ASR)

### Qwen3-ASR (основной, рекомендуется)

```sh
npm run setup:qwen:mac
```

Создаёт `.runtime/qwen-venv`, ставит `mlx-qwen3-asr==0.4.4` и скачивает `moona3k/mlx-qwen3-asr-0.6b-4bit` (~0.5 ГБ, ревизия `4c59c533f95c84afb796655e814709034f826f04`) в `.runtime/huggingface`. Это community-реализация на MLX, а не официальный CUDA-рантайм. При старте сервер прогревает модель коротким тихим фрагментом и только после этого разрешает запись.

Если окружение Qwen найдено, он становится движком по умолчанию. Можно работать только с Qwen, без Whisper.

### Whisper.cpp (альтернатива для сравнения)

Нужен `whisper-server` из [whisper.cpp](https://github.com/ggml-org/whisper.cpp) и **мультиязычная** GGML-модель. Модели `.en` не подходят. Сервер сам запускает `whisper-server` на порту 4318, если найдёт модель. Путь по умолчанию: `~/.cache/whisper-models/ggml-large-v3-turbo.bin`. Если Whisper уже запущен отдельно, укажи `WHISPER_URL`.

## 2. Перевод (Ollama)

### Локально в проекте (macOS)

```sh
npm run setup:translation:mac            # TranslateGemma 4B
npm run setup:translation:mac -- qwen3:4b  # или другая модель
```

Скачивает официальный Ollama v0.40.15 с проверкой контрольной суммы (~186 МБ) и модель (~3.3 ГБ) в `.runtime/`. Ollama работает на порту 11435 с `OLLAMA_NO_CLOUD=1`. Скрипт создаёт `.env` или дописывает недостающие ключи `OLLAMA_MODEL`, `OLLAMA_URL`, `OLLAMA_BIN`, сохраняя все существующие значения. Существующая установка Ollama не трогается.

### Уже установленная Ollama

```sh
ollama pull translategemma:4b
ollama pull qwen3:4b      # для подстрочного перевода (значения слов)
```

Для подстрочного перевода нужна вторая модель, `GLOSS_MODEL`, по умолчанию `qwen3:4b`. Без неё перевод фраз работает, а значения слов — нет.

### Профили промптов

- `translategemma`: одно сообщение пользователю, ответ простым текстом с потоковой выдачей. Выбирается автоматически для имён на `translategemma`.
- `chat`: thinking выключен, ответ в виде JSON. Подходит для qwen3 и других чат-моделей.

Для своих имён моделей профиль задаётся через `OLLAMA_PROFILE`.

## Переменные окружения

`.env` читается при старте. Переменные из shell имеют приоритет. Шаблон — `.env.example`.

| Переменная | По умолчанию | Назначение |
| --- | --- | --- |
| `CLARO_DATA_DIR` | `<проект>/data` | Каталог SQLite-хранилища разговоров, файл `claro.sqlite`, права каталога `700` и файла `600` |
| `CLARO_STORAGE` | включено | `off` отключает хранилище и API разговоров. Сохранение также отключается настройкой «Сохранять разговоры» в клиенте |
| `PORT` | `4317` | Порт приложения (только 127.0.0.1) |
| `ASR_ENGINE` | `qwen`, если установлен, иначе `whisper` | Движок по умолчанию. В интерфейсе можно переключить |
| `QWEN_PYTHON` | `.runtime/qwen-venv/bin/python` | Python с mlx-qwen3-asr |
| `QWEN_MODEL` | локальный снапшот 0.6B-4bit | Другой чекпойнт. Его нужно скачать заранее |
| `WHISPER_PORT` | `4318` | Порт управляемого whisper-server |
| `WHISPER_BIN` | `whisper-server` из PATH | Путь к бинарнику |
| `WHISPER_MODEL` | `~/.cache/whisper-models/ggml-large-v3-turbo.bin` | GGML-модель |
| `WHISPER_CPU` | — | `1` отключает Metal |
| `WHISPER_URL` | — | Подключиться к уже запущенному Whisper вместо собственного |
| `OLLAMA_MODEL` | — | Модель перевода фраз. Пусто — перевод выключен |
| `OLLAMA_URL` | `http://127.0.0.1:11434` | Адрес Ollama, только loopback |
| `OLLAMA_BIN` | — | Запустить Ollama автоматически, если адрес недоступен |
| `OLLAMA_PROFILE` | авто | `translategemma` или `chat` |
| `OLLAMA_NUM_GPU` | `0` | `0` — CPU, `99` — полный GPU. GPU быстрее, но делит Metal с Qwen |
| `OLLAMA_NUM_THREAD` | `2` | Потоки CPU для перевода |
| `GLOSS_MODEL` | `qwen3:4b` | Модель значений слов |
| `GLOSS_URL` | `OLLAMA_URL` | Отдельный экземпляр Ollama для значений слов |
| `GLOSS_NUM_GPU` | `0` | GPU для значений слов |
| `CLOUDFLARED_BIN` | `cloudflared` из PATH | Для `npm run remote` |
| `QWEN_SETUP_PYTHON` | `3.12` | Версия Python для venv Qwen (передаётся в `uv venv --python`) |
| `CLARO_BENCHMARK_URL` | `http://127.0.0.1:4317` | Адрес Claro для скриптов бенчмарков |

Модель значений слов создаётся, только когда задан `OLLAMA_MODEL`.

Модели в Ollama остаются в памяти 30 минут после последнего запроса. При запуске `main()` дожидается доступности Ollama в фоновом задании и один раз прогревает модели перевода и значений слов синтетической фразой. Прогрев не занимает очередь подсказок. Ошибка выводится одной общей строкой для соответствующей модели, субтитры продолжают работать.

**Текущая конфигурация этого Mac** (M4, 16 ГБ): TranslateGemma 4B на GPU (`OLLAMA_NUM_GPU=99`), Qwen3 4B для значений слов на CPU, Ollama проекта запускается через `OLLAMA_BIN`.

## Запуск

```sh
npm start            # запуск из Терминала
./start.command      # также открывает окно браузера
```

Двойной клик по `~/Applications/Claro.command` или `start.command` проверяет `/api/config` на настроенном `PORT`. Если сервер уже работает, открывается окно. Иначе запускается сервер, окно открывается после ответа API с ожиданием до 30 секунд. Chrome открывается в режиме приложения, при его отсутствии используется браузер по умолчанию. Терминал показывает «Claro работает. Закройте это окно, чтобы остановить». Закрытие окна или Ctrl+C останавливает сервер и его дочерние процессы.

Строка состояния показывает загрузку распознавания либо действие для исправления ошибки. Если распознавание не установлено, экран «Разговор» предлагает копируемую команду `npm run setup` и инструкцию. При недоступном переводе показывается «Перевод недоступен».

В настройках группы «Данные» есть «Установить как приложение». При наличии события `beforeinstallprompt` открывается системный запрос браузера. В остальных случаях выводится подсказка «В Chrome: меню ⋮ → Установить Claro». Доступность установки зависит от браузера.

Серверные изменения требуют перезапуска. Файлы из `public/` отдаются с диска без сборки, поэтому достаточно обновить страницу.

## Удаление

```sh
bash scripts/uninstall.sh
```

Скрипт останавливает серверы из этой папки проекта, удаляет `.runtime/` с моделями и окружениями и созданный ярлык. Удаление `data/` с разговорами и папки проекта подтверждается отдельно через Терминал. При сохранении `data/` сохраняется и содержащая её папка проекта. Внешний каталог `CLARO_DATA_DIR`, общие Node.js, uv и сторонние модели Whisper сохраняются.

## Бенчмарки

```sh
npm run benchmark:asr -- /path/to/speech.wav --interval=1.5 --translation --output=.runtime/benchmark.json
node scripts/benchmark-fleurs.mjs .runtime/eval-fleurs-es asr|live|cadence|translation
```

Запускай при остановленном микрофоне: тесты делят движки с живой записью. На вход — WAV PCM16 моно 16 кГц, 0,1–15 с. Результаты и методика — в [benchmarks/](benchmarks/).
